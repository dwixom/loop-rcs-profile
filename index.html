What this pilot does

Loop is testing private founder conversations about company work. Messages can carry assignments, focused questions, decisions, and status updates. Demonstration role output is labeled Demo; a demonstration is not an actual product assessment.

This is a closed test with invited, accepted test devices. Public enrollment and customer messaging are not available here. This page provides the pilot's sender information while the main Loop website is being built.

Messages and support

Message frequency varies with the conversation and work updates. Message and data rates may apply. Reply STOP to stop messages, START to opt back in, or HELP for assistance. For operator support or a privacy request, use the private channel through which you were invited and identify the request as a Loop pilot request.

This pilot uses RCS; SMS fallback is disabled. Consent to messaging is not a condition of a purchase. There is no purchase or public sign-up on this page.
